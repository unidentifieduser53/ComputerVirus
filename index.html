What is a Computer Virus?

A potentially damaging program

designed to affect, or infect, a computer negatively by altering how it works without the user's knowledge or permission.

A segment of program code

that implants itself in a computer file and spreads systematically from one file to another.

Written on purpose:

Programmers create viruses for a specific reason, usually to cause a certain type of symptom or damage.

Virus Detection & Removal: Antivirus Program

  • Protects a computer against viruses by identifying and removing any computer viruses found in memory, on storage media, or on incoming files.
  • Protects against malicious ActiveX code and Java applets that might be included in downloaded files.
  • Scans programs that attempt to modify the boot program, the operating system, and other programs normally read from but not modified.
  • Identifies a virus by looking for a specific pattern of known virus code called a virus signature, compared against a virus signature file.

How Does a Computer Get Infected?

✉️Opening email attachments
⬇️Downloading infected software
🚫Pirating software, music, and/or movies
🔄Not running the latest updates
⚠️No antivirus / spyware scanner installed
🐞Accepting prompts or files without reading them

How to Avoid a Virus

🔄Keep your Windows/OS up-to-date.
🛡️Keep your antivirus software up-to-date.
🔒Take extra care with file sharing.
🚫Don't click on tempting ads and pop-ups, especially those offering free items.
✅Be careful with forums, social networking sites, and message boards.
🛡️

Quick Recap

4 Types of Viruses

3 Ways to Prevent Infection

  • Update OS and antivirus regularly
  • Avoid suspicious downloads, pop-ups, and pirated files
  • Be cautious with email attachments and file sharing

Let's Check Your Understanding!

Scenario 1: You receive an email attachment from an unknown sender. What should you do, and why?
Don't open it. Delete it (or report it) and let your antivirus scan it if unsure, because email attachments are a common way viruses get in.
Scenario 2: A downloaded game looks legitimate but is secretly harming your files. What type of virus is this?
A Trojan horse virus. It is designed to look like a legitimate program while hiding the harmful code.
Evaluation: (1) What's the difference between a File virus and a Trojan horse? (2) Name one way a computer gets infected and one way to prevent it.
(1) A file virus attaches to or replaces program files and spreads to any file that accesses the infected program; a Trojan horse hides in or imitates a legitimate program. (2) Infected by opening email attachments; prevented by keeping the OS and antivirus up to date.
